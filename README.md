# Rotora Quiz

A free study quiz maker that runs entirely in the browser. No account, no server, no AI.

- Paste questions and answers, and it turns them into a multiple choice, identification, or mixed quiz.
- Save quizzes, put them in folders, and track your best score.
- Everything is stored in the visitor's own browser (localStorage). Nothing is uploaded anywhere.

## Use it

Open `index.html` in any browser, or visit the GitHub Pages link for this repository.

## Paste formats

- `Question | Answer`
- `1. Question` then `Answer: ...`
- `Q:` and `A:` lines
- Questions with choices (a, b, c, d) and `Answer: B`
- Alternative accepted answers: `Carbon dioxide; CO2`
